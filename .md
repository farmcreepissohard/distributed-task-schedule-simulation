Chặng 1: Nền móng Database & Cơ chế LockThiết kế cấu trúc bảng jobs trong PostgreSQL để lưu trạng thái, metadata và thời gian retry.Thiết lập câu lệnh SQL SELECT ... FOR UPDATE SKIP LOCKED. Đây là linh hồn của hệ thống, giúp các worker đọc database mà không bị đụng độ nhau.

Chặng 2: Khởi tạo Spring Boot & Cấu hình CoreSetup project Java 21+ và Spring Boot.Cấu hình Virtual Threads thay thế cho Platform Threads truyền thống. Bước này sẽ cho nhà tuyển dụng thấy bạn biết cách scale hệ thống xử lý hàng chục ngàn I/O operations mà không tốn nhiều RAM.

Chặng 3: Xây dựng Worker DispatcherViết logic polling liên tục để tìm kiếm các task đang ở trạng thái PENDING.Xử lý retry logic (Exponential Backoff): Nếu một task thất bại, hệ thống tự động tính toán thời gian dãn cách để thử lại lần sau.

Chặng 4: Testing & Scale (Điểm chốt hạ CV)Viết Unit Test cho các case Race Condition.Đóng gói bằng Docker. Chúng ta sẽ chạy thử 3-5 container cùng kết nối vào một database để chứng minh hệ thống hoạt động hoàn hảo trong môi trường phân tán (Distributed).
